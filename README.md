## ชาแนลอื่นๆ

ร้านที่ใช้ชาแนลเฉพาะของตัวเอง เปลี่ยน `center` ในลิงก์ด้านบนเป็นชื่อชาแนลของร้านนั้นได้เลย (มีสองจุดในลิงก์) เช่น ชาแนล `demo`:

https://github.com/thanvasu-cloud/thanvasu-pos-releases/releases/download/channel-demo/ThanvasuPOS-Setup-demo.exe

Download ไฟล์ .exe สำหรับ Windows หรือ .apk สำหรับ Android

สามารถโหลดไฟล์เก็บไว้เอาไปติดตั้งในร้านอื่นได้เลย แค่เปลี่ยนชาแนล: กดที่เลข version ค้างไว้ แล้วจะขึ้น popup ให้แก้ชาแนล ให้ตรงกันกับใน workflow
